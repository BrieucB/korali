# Directory Guide

## Purpose
Korali test suites and build helpers.

## Specifics
This directory contains Meson test definitions plus unit, statistical, Python, and build-validation test assets for the local Korali fork.

## Provenance
Hand-maintained test infrastructure for the checked-out Korali source tree.

## Immediate Contents
- Subdirectories: `unit`, `statistical`, `python`, `build`.
- Files: top-level `meson.build`, `.gitignore`.

## Maintenance
Update this file whenever the test layout or major test responsibilities change.
